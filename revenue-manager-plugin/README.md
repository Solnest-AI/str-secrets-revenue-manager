# Revenue Manager plugin

This is the Revenue Manager itself: the skill, the database tables it keeps in your
Supabase, and the reference docs it reads while it works.

Setup and the full rundown live one folder up: `../README.md` and `../SETUP.md`.

What it does, short version: it walks the Revenue Flywheel on every call (Visibility,
Bookings, Reviews, Ranking), prices with a safety layer, tells you what your min price
should be, checks whether your PriceLabs rules are actually working, and changes a price
only when you say yes.

Built by Solnest AI.
